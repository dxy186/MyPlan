# AI 科学计划秘书 · 使用说明书

> 定位：一个懂你精力、能接作业、会拆任务、自动排程、动态调整、还让你有时间玩的私人 AI 助理。
>
> 一句话本质：**它不是「管理时间」，而是管理你的能量与承诺。** 用科学方法拆解目标，用精力数据匹配任务，用双轨引擎保证进度，用动态调整应对变化，用强制恢复期让你有时间玩。最终目标：**让你在低精力状态下也能持续前进，且不恨自己。**

---

## 0. 三分钟快速上手

新功能没有新增侧边栏入口，而是嵌在原有页面顶部，作为**子 Tab**。原有界面永远是第一个 Tab（默认打开），数据、习惯、入口全都不变。

跑通一次完整闭环，只要 6 步：

| 步骤 | 去哪 | 做什么 |
|:--|:--|:--|
| 1️⃣ 接作业 | 侧边栏 **SMART任务记录 → 任务池** | 贴 Canvas iCal 链接，或一句话录入「下周三交机器学习项目报告」 |
| 2️⃣ 拆目标 | 侧边栏 **SMART任务记录 → 目标拆解** | 填 SMART，点「本地拆解（离线）」或「AI 深度拆解」，再「写入 SMART 任务」 |
| 3️⃣ 打卡 | 侧边栏 **日历进度 → 精力仪表盘** | 记一次今天精力，AI 才知道什么时候该安排什么 |
| 4️⃣ 排程 | 侧边栏 **日历进度 → 双轨排程** | 录硬约束（课程/会议）→ 点「生成 / 重新规划」 |
| 5️⃣ 执行 | 侧边栏 **历史任务 → 时间记录** | 「▶ 开始」计时 →「■ 完成并记录」 |
| 6️⃣ 复盘 | 日历进度 → 双轨排程（底部「每日复盘」）/ 历史任务 → 时间记录（今日统计） | 看完成度、速率系数、碎片时间 |

> 排程页提示「目标库里还没有未完成任务」时，说明你还没走第 2 步——先去「目标拆解」建一个目标。

## 2. 逐面板图文说明

### 2.1 📥 信息采集 · 任务池

**位置**：`SMART任务记录 → 任务池`　**对应板块**：板块一（信息采集与上下文感知）
**作用**：让 AI「看到」作业——自动收集作业要求、课程表、DDL、考试安排。

```
┌─ 信息采集 · 任务池 ─────────────────── [ 清空任务池 ] ─┐
│                                                          │
│  ✍️ 手动补充                                             │
│  ┌────────────────────────────────┬──────────────┐       │
│  │ 输入一句话，自动识别日期        │ 加入任务池    │       │
│  └────────────────────────────────┴──────────────┘       │
│  例：下周三交机器学习项目报告 / 12月20日前完成论文初稿     │
│                                                          │
│  📚 Canvas / LMS 日历（iCal）                            │
│  ┌────────────────────────────────┬──────────────┐       │
│  │ https://.../feeds/calendars/…ics│ 拉取并导入    │       │
│  └────────────────────────────────┴──────────────┘       │
│  在 Canvas → Calendar →「Calendar Feed」复制订阅链接       │
│  ── 或粘贴 ICS 文本 ──                                    │
│  ┌────────────────────────────────┬──────────────┐       │
│  │ BEGIN:VCALENDAR ... END:VCALENDAR│ 解析粘贴内容  │       │
│  └────────────────────────────────┴──────────────┘       │
│                                                          │
│  🗂 任务池（3）                                            │
│  ┌────────────────────────────────────────────────────┐ │
│  │ [Canvas] 截止 2026-09-20                            │ │
│  │ 机器学习项目报告                                     │ │
│  │ 地点/课程：CS229                                    │ │
│  │ [→ SMART 任务]  [📅 加日历]  [删除]                 │ │
│  └────────────────────────────────────────────────────┘ │
└──────────────────────────────────────────────────────────┘
```

**三种采集方式**

| 方式 | 操作 | 说明 |
|:--|:--|:--|
| 自然语言 | 一句话填进输入框 →「加入任务池」 | 自动识别日期；识别不到会提示「未识别到日期，可稍后补」 |
| Canvas iCal | 粘贴订阅链接 →「拉取并导入」 | 自动去重（同标题+同日期）；可能出现 CORS 拦截 → 见 FAQ |
| 粘贴 ICS | 复制 ICS 全文 →「解析粘贴内容」 | 拉取失败时的可靠兜底 |

**任务池里每条能做三件事**

- **→ SMART 任务**：写入 `SMART任务记录`（默认象限：重要且紧急）
- **📅 加日历**：写入日历；若同名同日期已存在会提示「日历里已有同名同日期的事项」
- **删除**：只删任务池这条，不影响已进入任务记录/日历的条目

**来源标记**：每条任务前会显示来源 badge（`Canvas` / `手动` / `邮件` / `Syllabus`），一眼看出它是怎么进来的。

> 右上角「清空任务池」会二次确认，且不影响已经推进到任务记录/日历的条目。

### 2.2 🧩 目标拆解 · SMART / WOOP / HTA

**位置**：`SMART任务记录 → 目标拆解`　**对应板块**：板块二 + 板块三
**作用**：把模糊愿望变成科学可行的目标，再拆成可执行、有依赖、带执行意向的子任务。

```
┌─ 目标拆解 · SMART / WOOP / HTA ──────────────────────────┐
│                                                          │
│  1. 目标设定（SMART）                                     │
│  目标标题 (S)*   [ 例：12月20日前完成机器学习项目 ]        │
│  衡量标准 (M)    [ 如何算完成？ ]                          │
│  可行性说明 (A)  [ 为什么做得到？ ]                        │
│  相关性 (R)      [ 与长期目标的关系 ]                      │
│  截止时间 (T)    [ YYYY-MM-DD ]                           │
│  拆解策略  ( 时间递进型 ) ( 功能分解型 ) ( 里程碑型 ) ( 混合型 )│
│  难度星级  ⭐ ⭐ ⭐ ⭐                                     │
│                                                          │
│  2. 障碍预判（可空）· WOOP                                │
│  W [ W 愿望 ]   O [ O 最佳结果 ]   O [ O 核心障碍 ]        │
│  P [ P 如果[障碍]，那么我就…… ]                            │
│                                                          │
│  3. 智能拆解                                              │
│  [ 本地拆解（离线） ]   [ AI 深度拆解 ]                    │
│  总预估耗时：6 小时 · 里程碑 4 个 · 任务 14 个             │
│  MECE 检查提示： ✅ 检查通过   （若有问题则 ⚠️ 列出）       │
│                                                          │
│  任务树                                                   │
│  ┌─ 第 1 阶段：启动与信息收集 ─────────────── [删除] ─┐   │
│  │ 依据：按时间递进，先降低启动摩擦                    │   │
│  │ 成果：明确范围与资料                                │   │
│  │  🟢 整理资料归类，标注待解决问题                     │   │
│  │     如果[资料很乱]，那么我就[先建一个目录]           │   │
│  │     耗能：(高) (中) (低)   预估 [ 30 ] 分钟         │   │
│  │  ＋ 新增可执行任务（用动词开头）                     │   │
│  └────────────────────────────────────────────────────┘   │
│                                                          │
│  4. 可行性评估（TELOS）  82 分 ★★★★☆                     │
│  时间 T ▓▓▓▓▓▓▓░░  操作 O ▓▓▓▓▓▓░░   技术 E ▓▓▓▓▓░░░      │
│  经济 C ▓▓▓▓▓▓▓▓░  法律 L ▓▓▓▓▓▓▓▓▓                      │
│                                                          │
│  [ 保存目标 ]   [ 写入 SMART 任务 ]                       │
│                                                          │
│  📚 目标库（1）                                           │
│  ┌────────────────────────────────────────────────────┐ │
│  │ 机器学习项目 可行性 82 ★★★★☆ · 里程碑 4 · 截止 12-20 │ │
│  └────────────────────────────────────────────────────┘ │
└──────────────────────────────────────────────────────────┘
```

**要点**

- **SMART 只强制标题**，其余可先留空后续补；点「本地拆解」会提示「先填写目标标题」。
- **两种拆解**：`本地拆解（离线）` 用内置模板（时间递进 / 功能分解 / 里程碑 / 混合）立刻出结果；`AI 深度拆解` 调用 AI 智能体层，返回结构化 JSON，失败会提示「可先用本地拆解」。
- **任务树里每个任务前的圆点**：🟢 = 物理动作（以动词开头，可直接动手），🟠 = 非物理动作（建议改写）。这就是「物理动作约束」，用来降低启动摩擦。
- **执行意向**：任务若带「如果[障碍]，那么[行动]」，说明它已绑定触发器（Gollwitzer 执行意向）。
- **耗能标签**：每个任务标 高/中/低 耗能，排程时据此匹配精力时段。
- **MECE 检查**：自动校验子任务是否相互独立、完全穷尽，通过显示 ✅，有问题列出具体条目。
- **TELOS 可行性**：技术 / 经济 / 法律 / 操作 / 时间 五维打分，得出 0-100 分与星级。

**两个按钮的区别（很重要）**

| 按钮 | 写到哪 | 用途 |
|:--|:--|:--|
| **保存目标** | 目标库 `@myplan_goals` | 供「双轨排程」读取、生成日程 |
| **写入 SMART 任务** | 原「SMART任务记录」 | 把每个里程碑生成一条任务（标题为「目标 · 里程碑」，象限默认重要不紧急），子任务=里程碑下的任务 |

> 提示：排程引擎只会排「目标库」里未完成的任务。要让日程有东西可排，**先「保存目标」**。

**科学依据速查**：SMART（Doran, 1981）、WOOP（Oettingen, 2014）、HTA 层级拆解、MECE 原则、执行意向（Gollwitzer, 1999）、关键链瓶颈识别（Goldratt）、TELOS 可行性研究。

### 2.3 ⚡ 精力仪表盘

**位置**：`日历进度 → 精力仪表盘`　**对应板块**：板块四 + 板块九（碎片时间）
**作用**：量化精力，找出个人「黄金时段」和「低谷时段」，并给微休息建议。

│  最近打卡：2026-09-13 · 上午 · 睡眠 7.5h                  │

│                                                          │
│  精力曲线                                                 │
│   10│        █                                            │
│    8│   █    █    █                                       │
│    6│   █    █    █    █                                  │
│    4│                  █    █                              │

│  生理精力（权重 22%）  1-10       ← 疲惫 / 充沛            │
│  情绪精力（权重 18%）  1-10       ← 低落 / 愉悦            │
│  认知精力（权重 25%）  1-10       ← 迟钝 / 专注            │

│  备注 [ 今天状态如何？ ]                                   │
│  [ 保存打卡 ]                                             │
│                                                          │
│  碎片时间 / 微休息                                        │
│  现在推荐：微恢复                                          │
│  [ 开始 5 分钟微休息 ]   （计时中可「点此停止」）          │
│                                                          │
│  历史日志                                                 │
│  📋 精力日志（4）                                          │
│  ┌────────────────────────────────────────────────────┐ │
│  │ 2026-09-13 · 上午 · 7/10  睡7 生6 情8 认7 意7  [删] │ │
│  └────────────────────────────────────────────────────┘ │
└──────────────────────────────────────────────────────────┘
```

**要点**

- **四层精力模型**：意义 / 生理 / 情绪 / 认知，加权求和得当天分数（认知权重最高 25%）。
- **5 个 ScorePicker** 都是 1-10 拉杆，两端标注含义（如「疲惫 ↔ 充沛」）。
- **精力曲线**是 7 个时段柱状图：清晨 06-08、上午 08-11、中午 11-13、下午 13-17、傍晚 17-19、晚上 19-23、深夜 23-06。最高/最低时段会被标成 🌞 黄金 / 🌙 低谷。
- **同一天同一时段重复打卡会覆盖**，不会堆成一堆重复记录。
- **碎片时间推荐逻辑**：精力 < 4 → 微恢复；下一任务高耗能 → 微充电；精力 ≥ 7 → 微输入；其余 → 微整理。
- **微休息**基于 45-90 分钟超日节律，倒计时到点提示站起来、看窗外、深呼吸。

**科学依据**：Loehr & Schwartz 精力管理四层金字塔、超日节律、PlanClaw 5 维度加权算法、注意力恢复理论。

### 2.4 🗓 双轨排程（核心面板）

**位置**：`日历进度 → 双轨排程`　**对应板块**：板块五（核心）+ 板块七 + 板块八
**作用**：在 DDL 前完成，同时尊重精力，并预留玩的时间。

```
┌─ 双轨排程 ───────────────────────────────────────────────┐
│  进度轨保证「做得完」，精力轨保证「做得爽」。               │
│                                                          │
│  进度  目标进度 35%  (5/14)                               │
│        目标库里未完成任务 9 个                             │
│                                                          │
│  硬约束（先锁死，不可移动）                                │
│  ┌────────────────────────────────────────────────────┐ │
│  │ 每周 机器学习课  📚课程  周一 09:00-11:00           │ │

└──────────────────────────────────────────────────────────┘
```

**双轨的含义**

- **进度轨（硬约束）**：DDL、依赖关系、关键路径 → 保证「做得完」。
- **精力轨（软约束）**：精力等级、超日节律、任务耗能 → 保证「做得爽、不崩」。

**日程条目颜色**

| 颜色 | 类型 |
|:--|:--|
| 蓝 | 任务 |
| 灰 | 硬约束 |
| 绿 | 玩（每天固定娱乐时间，不可侵占） |
| 紫 | 缓冲日 |
| 黄 | 缓冲（吸收低能量日延误） |

**风险报告的三个档位**

- 🌞 **黄金档（做全）**：时间充裕，按完整标准完成。
- ⚪ **白银档（保核心）**：只保核心交付，砍掉可选加分项。
- 🥉 **青铜档（先交作业）**：时间/精力紧张时，先满足最低交作业标准。

**排程参数默认值**

| 参数 | 默认 |
|:--|:--|
| 规划天数 | 7 天 |
| 一天开始 / 结束 | 08:00 / 23:00 |
| 项目缓冲比例 | 25%（可选 20% / 25% / 30%） |
| 每天玩的时间 | 120 分钟 |
| 每周缓冲日 | 周日（当天不排任务，强制恢复） |
| 时间盒 | 45-90 分钟，盒间休息 10 分钟 |

**要点**

- 硬约束**先锁死**，排程时绝不被占用；每生成一次日程都会显示「生成于 …」。
- **一键重排今天 / 本周**：计划赶不上变化时手动触发，AI 按最新情况（新任务、实际耗时、精力）重新计算剩余排程。
- 若完成概率偏低、有任务排不下，风险报告会明确列出「排不下的任务」，并给出质量档位建议。
- 排程页无任务时提示：`目标库里还没有未完成任务，先去『目标拆解』页拆一个目标。`

**科学依据**：关键链项目管理（Goldratt，缓冲 20-30%）、约束满足问题（硬约束锁定）、超日节律（时间盒 45-90 分钟）、帕金森定律（时间盒压缩）、帕累托法则（质量弹性）、注意力恢复理论（强制玩的时间）。

**要点**

- **一键计时**：任务输入框可手填，也可点下方任务 chip（chip 前缀 🔴/🟡/🟢 表示高/中/低耗能）。点「▶ 开始」计时，点「■ 完成并记录」自动生成一条时间记录，并更新速率系数。

- **生活琐事一键记**：点 chip 即按标准时长（如「吃早饭 20」）记一笔，不用手填分钟。
- **碎片时间**：类型可选 微输入 / 微整理 / 微恢复 / 微充电 / 刷手机，记录后统计近 7 天分布。

- **分类颜色**：任务（蓝）/ 生活琐事（黄）/ 碎片时间（紫）。

**科学依据**：RescueTime / Toggl 类时间追踪、时间块法、规划谬误修正（实际 vs 预估校准）、自我觉察（碎片时间日志）。

## 3. 用户完整工作流（10 步闭环）

```
1. 接入 Canvas/邮箱  → AI 自动抓取作业 DDL 和课程表        （任务池）
2. 用户输入目标（如「12月20日前完成机器学习项目」）          （目标拆解）
3. AI 进行 SMART 校准 + WOOP 向导 + 可行性评分              （目标拆解）
4. AI 拆解为里程碑和可执行任务，标注依赖、耗能、执行意向      （目标拆解）
5. 读取可穿戴设备/手动打卡，评估当前精力                     （精力仪表盘）
6. 双轨排程：硬约束锁定 + 精力匹配 + 缓冲预留 + 玩的时间      （双轨排程）
7. 用户执行任务，一键计时或自动记录                         （时间记录）
8. AI 对比实际 vs 预估，动态调整剩余排程                     （双轨排程）
9. 每日/每周复盘，生成报告，更新用户画像                     （双轨排程 / 时间记录）
10. 循环迭代，越来越懂你
```

任务池 ──「→ SMART 任务」──► SMART任务记录 ──「加日历」──► 日历

```

## 5. 常见问题（FAQ）

**Q1：贴了 Canvas iCal 链接点「拉取并导入」，提示拉取失败 / 网络错误？**
A：浏览器可能因 **CORS 跨域** 拦截了请求。解决办法：在 Canvas 里打开订阅链接，在浏览器中另存或复制 ICS 全文，粘到下方「粘贴 ICS 文本」框，点「解析粘贴内容」。CORS 是浏览器安全策略，不是功能坏了。

**Q2：任务池加入后，日历里没出现？**
A：任务池条目需要点条目上的「📅 加日历」才会写入日历；只点「加入任务池」只是进池。同日同名会提示已存在，不会重复添加。

**Q3：双轨排程提示「目标库里还没有未完成任务，先去『目标拆解』页拆一个目标」？**
A：排程只读取**目标库**（`@myplan_goals`）里未完成的任务。请到「目标拆解」建目标，拆解后点 **「保存目标」**。

**Q4：「保存目标」和「写入 SMART 任务」到底点哪个？**
A：想生成日程 → 点「保存目标」（进目标库，供排程读取）；想让任务出现在原来的 SMART 任务列表 → 点「写入 SMART 任务」。两个可以都点。

**Q5：AI 深度拆解没反应 / 报错？**
A：AI 拆解需要配置可用的 LLM API Key。未配置或网络不通时，先用「本地拆解（离线）」，它是纯本地模板，不依赖网络。

**Q6：精力打卡为什么同一天只看到一条？**
A：设计上「同一天同一时段覆盖」以免重复堆积。换一个时段再打卡会新增一条。

**Q7：日程里的「玩」时间能改吗？**
A：可以，在「排程参数 → 每天玩（分钟）」调整，默认为 120 分钟。它是硬约束，排程时不会被任务侵占。

**Q8：想重新规划本周怎么办？**
A：在「双轨排程」的风险报告里点 **「🔄 一键重排今天 / 本周」**，AI 按最新情况重算剩余排程。

**Q9：没设置可穿戴设备，能用吗？**
A：能。所有精力数据都可以手动打卡（4 个层级 + 睡眠时长），手动打卡是最低门槛的起步方式。
