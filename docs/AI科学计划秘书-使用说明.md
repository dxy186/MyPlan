# MyPlan · 使用说明

> 定位：一个懂你精力、会拆任务、自动排程、按真实进度持续调整、还让你有时间玩的私人 AI 计划秘书。
>
> 一句话本质：**它不是「管理时间」，而是管理你的能量与承诺。**

---

## 1. 界面地图：5 个入口

| 入口 | 做什么 |
|:--|:--|
| 📅 **日历**（默认首页） | 原来的「日历进度」：月视图、双击日期管理「我的事项」、固定日程、完整时间轴；顶部显示正在 / 下一项和计时；格子里浅灰斜体是自动排进来的任务 |
| 🏠 **今天** | 跟 AI 说话、计时、我现在有空、今明两天时间轴、早上计划、晚上复盘 |
| 📋 **任务** | 所有任务在一个列表里（按目标分组）；新目标拆解、任务池导入、WOOP |
| 📊 **复盘** | 7 天概况、勋章、时间记录、精力、已完成、习惯档案 |
| ⚙️ **设置** | 作息与排程、AI Key、提醒、数据备份、说明 |

**所有页面用同一份数据。** 在任何地方加任务、改时长、勾完成、加固定日程，排程都会从现在起自动重排，其他页面马上看到。任何页面按 **Ctrl+K** 回到「今天」并开始跟 AI 说话。

第一次使用前：到 **⚙️ 设置 → 🤖 AI** 填好 DeepSeek API Key，再到 **🕘 作息与排程** 设好一天的开始 / 结束时间、每天玩多久、休息日。

## 2. 🏠 今天

从上到下：

1. **正在 / 下一项**：现在该做什么、还剩多久、下一项；右边「🔔 开启到点提醒」。
2. **现在精力怎么样？**：3 小时内没记过精力时出现，点「有点累 / 一般 / 精力好」，用来挑任务和排时段。
3. **🔁 自动补排**：错过的任务块（没计时也没完成）会被挪进后面的空档，这里告诉你挪到了哪天几点。
4. **🌙 晚上复盘**（默认 21:00 后）/ **☀️ 早上计划**（5:00–14:00）。
5. **和 AI 说话**：说要做什么、做完了什么、想怎么调整，或者问问题（今日报告、效率建议、怎么拆解目标）。需要改数据时，AI 会给出「调整方案」，可以直接点「高 / 中 / 低」改耗能、改时长，确认后才生效；不满意就接着说。不知道说什么就点「💡 常用说法」。
6. **⚡ 我现在有空 / ⏱ 计时器**：全应用只有这一个计时器。可以从这里、从时间轴任务块的「▶ 开始计时」、或从「任务」页任务旁的 ▶ 开始。超过预估时会问「还要多久」：还要 15/30/60/120 分钟、明天继续、已完成，点一下就重排。做完一段会问整个任务完成了没有。
7. **接下来的安排**（在「今天的计划」下面、AI 输入框上面）：今天（从现在起）和明天的时间轴。点任务块可以改耗能、总时长、时段、开始计时、标记完成或删除任务。截止前排不下的任务会排在截止后最早的空档，并标「⚠️ 已超过截止」。
8. **🧠 我的习惯档案**（页面最下面）。

### AI 能听懂的话（举例）

- 新的事：「这周五前要交实验报告，大概 4 个小时」「下周三考高数，帮我安排复习」「帮我拆解期末论文，月底交」
- 固定时间：「今天下午 3 点到 5 点开组会」「每周二、四上午 8 点到 10 点上课」「明天的组会取消了」
- 汇报进度：「高数作业做完了」「报告写了 2 小时还没完，还要 1 个半小时」
- 调整：「把写报告挪到上午」「PPT 下周再做」「查文献挺费脑子的」「今天太累了，把难的往后挪」
- 记住习惯：「记住：周末上午我不想学习」「以后晚上 10 点后别给我排任务」「忘掉周末上午那条」
- 提问：「给我一份今日报告」「这周还排得下吗？」「我最近效率怎么样？」

做不到的：指定几点几分做某个任务（只能上午 / 下午 / 晚上，或者把它说成固定日程）、设置「先做完 A 才能做 B」。

### 🧩 帮我拆：不知道怎么拆、每步要多久

任务旁边的 🧩（日历「我的事项」里、今天页任务块面板里、任务列表里），或在日历添加时开头写 `?`（如 `?写期末论文`）：

1. 信息不够时，AI 先问你最多 2 个问题（可以跳过）。
2. 给出 3–6 个步骤：每步做什么、要多久（按你的速率系数和这类任务的习惯放宽）、耗能、哪天做（看每天还剩多少空闲，避开固定日程，截止前留缓冲）。第 1 步故意很小（≤15 分钟），帮你开个头。
3. 在弹窗里每一步都能改名字、时长、耗能、日期（‹ › 前后挪一天），可以删步骤、加步骤，不满意点「重新拆」。
4. 点「确认拆分」：原任务留在「📋 任务」列表里变成**父任务**（加粗，显示「🧩 已拆成 N 步 · 完成 x/N」和小进度条），拆出来的步骤作为**子任务**缩进显示在它下面，点 ▾ / ▸ 展开收起。
   - 父任务自己不再排程，日历里也不重复显示；每个子任务出现在它被分到的那天，后一步一定排在前一步之后。
   - 子任务全部勾完，父任务自动完成；勾父任务，子任务一起完成；删除父任务会连子任务一起删。
   - 对父任务再点 🧩 可以重新拆（旧的子任务会被替换）；对某个子任务点 🧩 还能再往下拆一层。

## 3. 📋 任务

子页面：

- **📋 全部任务**：按目标分组的唯一任务列表。
  - 顶部快速添加任务，可选放进哪个目标（默认「日常安排」）和截止日。
  - 筛选：今天 / 7 天内 / 全部未完成 / 已完成；四象限：重要紧急 / 重要 / 紧急 / 其他 / 未分类。
  - 每个目标可以设四象限、看进度、删除；每个任务可以勾完成、点 ▶ 计时、点开改名称 / 时长 / 耗能 / 截止 / 时段或删除。
  - 「＋ 新建目标」：只填名称、截止、四象限，再自己加任务或让 AI 拆。
- **拆解大任务**：点任务右边的 🧩，AI 会结合你的时间和 WOOP 把它拆成子任务。
- **📥 导入 · 任务池**：Canvas / iCal 链接或粘贴 ICS 文本、手动收集；每条可以「🎯 作为目标」或「📝 作为小任务」加入任务。
- **🧭 WOOP**：心理对照四步走；保存后点「➕ 变成目标」即可加入任务，执行意向会挂在第一步任务上。

旧版「SMART 任务记录」的任务（包括已完成的）和旧日历里单独添加的事项，第一次打开新版时已自动合并进来，四象限、SMART 要素都保留；已完成的在「复盘 → 已完成」里能看到。

---

### 📌 固定日程（任务 → 固定日程）
所有固定日程一览：「每周重复」和「单次」两组，同名同时间的每周日程合成一行（如「每周二、四 08:15–09:30 音乐课」）。可以「＋ 添加」（每周选几天，或只某一天）、「编辑」、「删除」。跟 AI 说的固定日程点「应用」后也会出现在这里；日历里显示为绿字。

## 4. 📅 日历（以日历为中心）

打开 MyPlan 默认就是日历。设计和用法和原来的「日历进度」一样，同时和任务、排程、AI 打通：

- **顶部一条**：现在该做什么、下一项；正在计时时显示计时和「■ 这段做完了」，结束后问整个任务做完没有。
- **格子**：你自己写的事项照旧显示（颜色、加粗、划线都保留）；**浅灰斜体**的是系统自动排进这天的任务。农历、休 / 班、格子背景色照旧。
- **一站到底（都在当天弹窗里）**：
  1. **记下来**：在「添加新事项」里用快捷写法——`写报告 2小时`（任务，时长 120 分钟）、`!复习高数 90分钟`（开头 `!` = 高耗能）、`15:00-17:00 开组会` / `下午3点-5点 开组会` / `9点半 晨会`（有时间的变成固定日程，排程会避开）、`每周二、四 8:00-10:00 高数课` / `每周一到五 9点-12点 上班`（每周重复的固定日程）、`取快递`（普通小任务）。时长也可以写 `1.5h`、`90min`、`半小时`。写在哪天就是哪天做。
  2. **看安排**：每个事项下方显示系统排的时间「🕐 14:00–16:00」，排不下会标「⚠️ 这天排不下」；固定日程单独列在「📌 固定日程」里，可以删除。
  3. **开始做**：今天的弹窗最上面有「▶ 开始下一项」；每个事项和自动排进来的任务旁也有 ▶。
  4. **做完**：在日历顶部那条点「这段做完了」，选做完了 / 还没。
  5. **有变化**：弹窗底部「🤖 跟 AI 说这天的安排」。
  6. **晚上复盘**：复盘时间（默认 21:00）后，今天没做完的事项下面会出现「明天继续 / 放一放（3 天后）」；过期没做完的还多一个「挪到今天」。
- **双击日期 →「我的事项」**：
  - 照旧可以添加、勾完成、上下调顺序、双击名称重命名（单击不做任何事）、🎨 改颜色加粗、删除。要换日期可以用晚上的「明天继续 / 放一放」，或跟 AI 说。
  - 每个未完成事项旁多了 **▶**：点一下开始计时（顶部那条会显示）。
  - 下面列出「🗓 自动排进这天的任务」，同样可以点 ▶ 开始。
  - 最下面「🤖 跟 AI 说这天的安排」：比如「这天下午要开会，把作业挪到晚上」，会跳到「今天」页让 AI 出方案，确认后生效。
- 日历里的事项就是带截止日的任务：在这里加的事项会出现在「任务 → 日常安排」里并参与排程；在任务页改了截止日，事项也会挪到对应的那天。
- 弹窗里还有：**「🕘 这天的完整时间轴」**（点开看从早到晚所有块，包括玩的时间、休息日，排在截止后的标 ⚠️）、**「✅ 这天完成的」**、**「📌 固定日程」**（可删除）。
- 原来的「双轨排程」「今日记录」子页都已合并或移走：排程和固定日程在当天弹窗里；精力打卡在「📊 复盘 → ⚡ 精力」（今天页也能一键记精力）。

## 5. 📊 复盘

- **📊 概览 · 勋章**：最近 7 天完成数、专注时间、有计时的天数、复盘天数、未完成和已过截止数；勋章根据真实数据点亮（完成第 1 个任务、专注 10 小时、连续一周计时、连续复盘、按时交付、见缝插针、了解自己等），未获得的显示进度。
- **⏱ 时间记录**：今日统计、生活琐事一键记、碎片时间日志、速率系数（实际 ÷ 原始预估，同一任务多次计时合并、任务完成后才计入）、全部记录。
- **⚡ 精力**：完整的 5 维度精力打卡、精力曲线、日记。
- **✅ 已完成**：所有完成的任务，按完成日期分组。
- **🧠 习惯档案**：你让 AI 记住的偏好 + 从数据里发现的规律（各类任务的速率差异、哪个时段最常按时开始、做事时间分布、工作日 vs 周末、复盘原因）。排程会自动给常低估的那类任务多留时间。

## 6. ⚙️ 设置

- **🕘 作息与排程**：一天开始 / 结束、每天玩的时间、每周休息日、一次最多 / 至少专注多久、块间休息、往后排几天。保存后立刻按新设置重排。
- **🤖 AI**：DeepSeek API Key、模型、测试连接。
- **🔔 提醒**：开关、任务提前几分钟提醒、晚上复盘时间。能弹系统通知就弹；不能（比如在 Claude 内置浏览器里）就用页面内提醒：右上角提示 + 提示音 + 标签页标题闪烁，需要 MyPlan 开着。
- **💾 数据备份**：导出 / 导入 / 撤销上次导入。数据只存在这台电脑（这个浏览器）里，换电脑、清缓存、在网页版和桌面版之间搬数据都要靠它。旧版本导出的备份导入后会自动重新合并任务。

## 6.5 每天用起来：打卡、提醒、庆祝、小结

- **🔥 连续打卡**：某天「勾掉至少一项任务」或「做了晚上复盘」就算打卡。日历顶部和今天页都显示「连续 N 天」。断一天没关系——昨天断了，今天勾一项就能接上（别连断两天）。
- **☀️ 早上提醒**（默认 8:30，设置 → 提醒 可改或留空关闭）：告诉你今天有几件事、第一件几点开始，点开直接打开日历里的「今天」。
- **🎉 完成就有回报**：勾掉任务有小动画和提示音；今天第一次打卡、连续天数 +1、今天的计划全部完成时，有更大的庆祝。
- **🌙 复盘后的 AI 点评**：晚上复盘提交后，AI 用 1–2 句话肯定你做到的事，并给明天一个小建议（需要在设置里配好 AI Key）。到复盘时间还没复盘，日历顶部会出现「🌙 1 分钟复盘今天」。
- **🎭 点评的语气**：设置 → AI →「点评的语气」可选「效率教练」「爱莉希雅风」或自定义一段风格描述，点「试一句看看」先听听效果。只改说话风格，数字和建议仍按真实数据。
- **📅 每周小结**：周日 18 点后（周一、周二也能补看）今天页出现小结卡片：完成数、专注时长、最好的一天、下周截止的任务，加上 AI 写的 2–3 句话。周日 20:00 会提醒一次。
- **💻 桌面版**：开机自动启动（藏在托盘里）、点 × 只是藏到托盘、到点弹 Windows 系统通知、点通知直接打开对应页面。托盘图标右键可以关掉开机自启或彻底退出。

## 7. 常见问题

- **为什么某个任务没出现在时间轴上？** 可能设了「X 号以后再做」、在休息日、前置任务没完成，或者已经排到了往后排的天数之外。到「任务」里看它的「排在 …」。
- **截止前排不下怎么办？** 页面会提示；任务会被排到截止后最早的空档。可以跟 AI 说「把 XX 往后挪」「XX 不做了」，或调整作息设置。
- **AI 说加好了，任务列表里却没有？** AI 给的是「调整方案」，要点「确认」才生效。
- **数据会丢吗？** 都存在本地。定期在「设置 → 数据备份」导出一份放到网盘。
